# Contributing to Milk Parlor

Submit a focused pull request that states the problem, the smallest change, and
the direct smoke you ran. Keep the gateway CPU-only and dependency-light. Do
not add jobs, model weights, a database, a queue, provider orchestration, broad
fixtures, or compatibility code for unreleased schemas.

Never include API keys, signing material, production traffic, or customer
content. Report vulnerabilities through [SECURITY.md](SECURITY.md).
